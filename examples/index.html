🎨 Component Examples

Vue Button Component

Vue button component with click counter. Each click increments the counter displayed next to the button.

React Button Component

React button component with identical behavior to Vue version. Uses React hooks for state management.

Features

  • Two variants: primary and secondary
  • Click counter that increments with each click
  • Disabled state support
  • Shared utility functions for both implementations
  • Fully styled and responsive
  • TypeScript support
  • Unit tests with Vitest
